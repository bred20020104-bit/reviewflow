# Planning skill

1. Inventory supplied paths and ranges; distinguish selection from fully available content. Identify related modules and their interfaces without inventing unseen code.
2. Allocate complementary correctness and security tasks within max_tasks. Use unique IDs and exact allowed paths. Prefer one grouped task per role when the cap is two, rather than covering only the first files.
3. Give each role an objective tied to the visible architecture (data flow, lifecycle or trust boundary), not a suspected answer. Both roles may inspect the same files independently.
4. For deduplication, compare trigger, root cause, affected operation and impact. Similar titles or nearby lines alone do not prove duplication. Group only supplied finding IDs with a reason; preserve distinct failure mechanisms. Grouping cannot accept or reject a finding.
