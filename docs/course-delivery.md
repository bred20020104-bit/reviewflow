## 建议演示脚本（总计约9分钟，须实际计时）

1. 0:00–0:45：问题与定位。开发完成后的仓库级检查，不要求 base/head/diff。
2. 0:45–1:45：五个角色与确定性权限层；指出 LangGraph 并非自由群聊。
3. 1:45–2:30：选择目录、HEAD 与 directory 区别、快照/过滤/覆盖。
4. 2:30–4:30：审查流程和证据；已接真实模型则展示脱敏真实案例，否则明确标记离线模拟，不能混用。
5. 4:30–6:00：先看报告再选择修复；演示 diff、授权摘要、独立 worktree，原目录保持不变。
6. 6:00–7:00：失败案例，展示证据无效/预算耗尽/验证阻塞；不能用模拟 accepted 冒充真实独立验证。
7. 7:00–8:15：实验对比及限制；未运行真实实验时明确说明，保留 TODO，不伪造指标。
8. 8:15–9:00：可复现性、贡献分工、后续工作。

没有 UI 不妨碍演示 CLI；使用更大终端字体、只展示必要输出，提前准备目录与命令。隐藏所有 Key、账号信息和未获准上传的源码。
